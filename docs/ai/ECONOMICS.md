# AI-экономика: журнал расхода, квоты, сценарии (C3-09, вход для economics.pdf у Pro)

Статус: **фактического сетевого расхода нет** — в сессии не было ключа провайдера. Ниже — формат фактического журнала, правила учета и сценарные оценки с явными допущениями. Оценки не являются измерениями; итоговые числа Pro берет из журнала одного финального прогона.

## Фактический журнал (`intel_ai_call`)

Каждая попытка вызова модели (ход, шаг инструмента, проверка подключения, повтор) пишется отдельной строкой: `created_at, correlation_id, purpose (assistant_turn | assistant_tool_followup | settings_check), provider, model_id (фактический из ответа), attempt, status (ok|error|rejected), error_kind, latency_ms, queue_ms, input_tokens, output_tokens, thought_tokens, cached_tokens, cost_usd (NULL = неизвестно), cost_source, prompt_version`. Текст запросов и ключи не хранятся.

Сводка: `GET /api/v1/assistant/usage[?since=ISO]` → число вызовов, ok/ошибки по видам, по назначению и модели, суммы токенов, вызовы без токенов, p50/p95 задержки успешных вызовов, сумма известной стоимости и число вызовов с неизвестной стоимостью.

- Gemini не возвращает стоимость: `cost_usd = NULL`, `cost_source = not_reported_by_gemini; derive from tokens x dated tariff`. Ноль не подставляется.
- OpenRouter: запрашивается `usage.include`; при наличии `usage.cost` записывается фактическая сумма, иначе NULL.
- Шлюз жюри возвращает те же поля и счетчик `attempts`.

## Число вызовов на запрос

| Ситуация | Вызовы модели |
|---|---|
| Распознанный однозначный запрос (все 18 открытых вопросов и 114 синтетических диалоговых кейсов) | **0** — детерминированный путь |
| Нераспознанный запрос, онлайн | обычно 2–3 (поиск → расчет → submit_answer), максимум 6 итераций |
| Повторы | ≤2 на итерацию при 429/5xx/тайм-ауте; учитываются в RPM/RPD и журнале |
| Проверка подключения | 1 вызов, ≤16 выходных токенов |
| Верификатор | локальный, 0 вызовов |

## Оценка токенов на вызов (измерение размера контекста, не токенизатора)

Фиксированная часть каждого вызова: системный prompt 1 275 символов + 11 схем инструментов 3 617 символов + сообщение пользователя ~200 символов ≈ **5 100 символов** (`prompt_version assistant-v1-2026-11-27`). Для смешанного русского/JSON текста это порядка 1 300–2 500 входных токенов (диапазон из-за неизвестной токенизации; уточняется по `input_tokens` журнала). Каждый следующий шаг добавляет результаты инструментов (≤6 000 символов, обычно 300–1 500).

Сценарный ход из 3 вызовов: вход ≈ 5 000–9 000 токенов, выход ≈ 150–450 токенов (+ thinking-токены, если модель их тарифицирует).

## Бесплатный режим

- Токенные расходы равны нулю **только в пределах квоты бесплатного проекта**; лимиты RPM/TPM/RPD для текстовых моделей Gemini публикуются в AI Studio проекта, а не на общей странице — их нужно снять с аккаунта команды и внести в профиль (`GLASSFLOW_AI_RPM/TPM/RPD`; по умолчанию консервативно 10 RPM / 200 000 TPM / 200 RPD).
- OpenRouter `:free`: 20 RPM, 50 запросов/день (1 000/день после покупки кредитов), неудачные попытки считаются.
- Free tier Gemini: содержимое может использоваться для улучшения продуктов Google — для хакатона передаются учебные данные; для пилота KSM выбрать платный режим обработки данных (TZ §5).
- Запас квоты конкурсного прогона: 30 закрытых вопросов × (0, если распознаны; иначе ≤6 вызовов + ≤2 повтора на вызов). Худший случай 30 × 6 × 3 = 540 вызовов; ожидаемый при текущей доле распознавания — близко к нулю. Проверить до 29.11 (TZ §26).

## Платный сценарий (только явный `paid_enabled` с бюджетом)

Тариф (дата проверки 27.11.2026, aistudio.google.com/docs/pricing, USD за 1M токенов): `gemini-3.8-flash` вход $0,75 / выход $3,75 (промо до 31.12.2026), `gemini-3.5-flash-lite` $0,30 / $2,50.

Формула: `cost_usd = Σ (input_tokens × in_rate + (output_tokens + thought_tokens_if_billed) × out_rate) / 1 000 000` по журналу. Курс тенге — датированный источник (например, официальный курс Нацбанка РК на дату расчета) — подставляет Pro; здесь курс не фиксируется.

Иллюстрация (не измерение): ход 3 вызова, 9 000 входных и 450 выходных токенов на `gemini-3.8-flash` ≈ 9 000×0,75/1e6 + 450×3,75/1e6 ≈ **$0,0085**. 1 000 онлайн-ходов в месяц ≈ $8,5 до конвертации. Доля онлайн-ходов зависит от того, сколько запросов не распознает детерминированный путь, — измеряется журналом пилота.

## Задержка

Фактический p95 ответа AI на 30 запросах реального профиля **не измерен** (нет ключа). Цель ТЗ — p95 ≤ 15 с. Детерминированный ход: p95 ≈ 25 мс; расчет p95 ≈ 6 мс (Linux-контейнер, `evidence/perf/performance.json`).
