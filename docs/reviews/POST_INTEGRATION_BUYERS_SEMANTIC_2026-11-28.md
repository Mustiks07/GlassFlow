# Independent semantic buyer review

All 50 original public profiles were individually read on 2026-11-28, rather than graded by HTTP status. Record-by-record support and uncertainties are in `data/buyers/independent_semantic_review_2026-11-28.json`. It preserves supplied names/categories and original source URLs as an audit, not an acceptance list. Identity, city and activity are the scope; no organization was contacted and no purchase demand is confirmed. A fresh search crawl does not establish that a historic venue is still operating.

The additive proposal `data/buyers/buyers.independent-v2.csv` and matching `evidence.independent-v2.json` contains exactly 50 distinct named public organizations/venues in nine categories, 49 Astana and one Karaganda. IDs of retained entities remain unchanged. Original C1/platform inputs are untouched. Runtime loading is a separate root integration step.
