# План измерения активного времени (для economics.pdf, владелец — GPT Pro)

ТЗ §28: трудозатраты измеряются сравнением одинаковых операций вручную и в приложении; `ответ_через_мин` — ожидание клиента, не часы работы.
Здесь только протокол. **Измерения этой веткой не выполнялись** — результаты записывает тот, кто их проведет.

## Протокол

- Исполнитель: один и тот же человек для обоих способов; порядок способов чередуется (A/B, B/A), чтобы не учитывать обучение.
- Начало: задание прочитано (текст запроса/исходные данные на экране). Конец: готов ответ клиенту или сохранено действие.
- Ручной способ: Excel/калькулятор + PDF прайса + таблица остатков + блокнот. Приложение: финальная сборка GlassFlow, обычный профиль.
- Секундомер; ошибки фиксируются отдельно (неверная цена/кусок = задание «не выполнено», время не идет в медиану).
- Отдельно: время установки и обучения (первый запуск по README).
- Отчет: медиана и разброс (min–max, IQR) по 10 заданиям для каждого способа; машина и версия сборки.
