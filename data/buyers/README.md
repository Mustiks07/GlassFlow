# Реестр покупателей: кандидат для GPT Pro (C1-07)

Файлы:
- `buyers_candidate.csv` — точная схема `name,city,category,url,why,source_url,score`, UTF-8 без BOM, запятая, стандартное экранирование.
- `evidence.json` — по каждой записи: стабильный внутренний ID (`B01…B50`), HTTP-статус, конечный URL и заголовок страницы-источника,
  подтверждение города и ключевого слова профиля, фрагмент текста, дата проверки, reviewer, правило дедупликации.
- `registry_source.py` — ручной отбор (одна строка на организацию), `verify_buyers.py` — воспроизводимая проверка и генерация обоих файлов:

```bash
python3 data/buyers/verify_buyers.py
```

Результат проверки 27.11.2026: 50 организаций, 50 уникальных названий, 49 в Астане (≥30), 9 из 9 допустимых категорий, 0 проваленных проверок.
Импорт в продукт: раздел «Продажа остатков» → «Импорт реестра» (`POST /buyers/import`, CSV + evidence).

## Методика

1. Кандидаты — публичные организации (сайты компаний, публичные карточки заведений на sxodim.com, профиль компании на kn.kz).
   Поисковые сниппеты использовались только для поиска адресов; ни одна запись не принята по сниппету.
2. Скрипт загружает `source_url`, требует HTTP 200, упоминание города и ключевого слова профиля в тексте страницы; anti-bot заглушки
   повторяются. Для записей, где `url` ≠ `source_url`, отдельно проверяется доступность `url`.
3. `why` — одно предложение о возможном применении небольших кусков стекла/зеркала; прошлые заказы и спрос не утверждаются.
4. `score` — экспертная релевантность профиля (мебель, окна, дизайн, салоны и фитнес с зеркалами выше; общепит ниже), не вероятность покупки.
5. Дедупликация: одна запись на организацию/бренд; филиалы и точки сети объединены; город — город проверенного объекта.
6. Личные контакты не собирались, сообщения никому не отправлялись.

## Ограничения (честно)

- Распределение категорий смещено к ТРЦ и общепиту (у них проверяемые публичные страницы); салон — 1 запись, магазин — 1.
- Часть карточек sxodim.com могла устареть (сайт показывает адреса и часы на дату публикации); перед питчем повторить `verify_buyers.py`.
- Сайты часть компаний (BI Group, Marriott/Hilton) блокируют автоматическую загрузку — такие организации не включены, а не включены «на доверии».
- Окончательный `buyers_top50.csv` выпускает и валидирует GPT Pro; файл кладется в корень сдачи, не в `closed_run`.
