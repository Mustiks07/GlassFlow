# Происхождение материалов

`GlassFlow_Development_Specification_v1.pdf` и `.txt` скопированы из согласованного результата без редактирования. PDF: 51 страница, SHA-256 `8c12555bb82f906dab1d83413f5569a2d4abeacb0f8f00dd254763683cc8cd3f`. `specification_structure.json` — машинно читаемая структура того же ТЗ, не новый текст.

Исходный `GENESIS_final_PACK_for_teams.zip` содержит **14 файлов**, включая PDF кейса. Все 14 извлеченных файлов в `inputs/` сверены побайтно с ZIP. Их размеры/SHA-256 находятся в `input_manifest.json`; git сохраняет их без изменения окончаний строк.

Исторический `analysis/source_manifest.json` содержит также три созданных Python cache-файла и поэтому имеет 17 записей. Эти cache-файлы не являются оригинальными входами организаторов и не включены в git. Для нового checkout и CI единственный актуальный manifest исходников — `docs/specification/input_manifest.json`. Старые исследовательские отчеты не переписываются задним числом.

`*_KEY.csv` — открытые проверочные эталоны для offline evaluation. Их наличие в исследовательском репозитории не дает права читать их из runtime AI/ranking/import pipeline. Столбец будущего возврата клиента также запрещен как признак предсказания.

Числа в `analysis/` относятся к выполненному исследованию открытого пакета. Они не подтверждают готовность продуктового движка, скрытый набор или место на конкурсе. Финальная реализация должна воспроизводить проверки заново.
